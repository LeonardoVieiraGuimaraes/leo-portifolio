# Leonardo Vieira Guimarães — Portfólio

Portfólio profissional de **Leonardo Vieira Guimarães**, Desenvolvedor Full Stack, Product Owner e Professor de TI, com mais de 8 anos em desenvolvimento de software e 12+ anos em educação/pesquisa.

🔗 **Live**: [leoproti.com.br](https://leoproti.com.br)
👤 **GitHub**: [@LeonardoVieiraGuimaraes](https://github.com/LeonardoVieiraGuimaraes)
💼 **LinkedIn**: [leonardo-vieira-guimaraes](https://www.linkedin.com/in/leonardo-vieira-guimaraes/)

## 🎨 Design

- **Tema**: Dark/Light mode com alternância dinâmica
- **Estilo**: Glass morphism, gradientes e animações suaves
- **Responsivo**: Mobile-first, adaptado para todos os dispositivos

## 🛠️ Stack Tecnológico

- **Frontend**: React 18.2 + TypeScript
- **Build**: Vite 4.4.5
- **Styling**: Tailwind CSS 3.3.5 + CSS personalizado
- **Icons**: React Icons
- **Deployment**: Docker + Nginx + Cloudflare Tunnel

## 🚀 Scripts Disponíveis

```bash
npm run dev                  # Iniciar servidor de desenvolvimento
npm run build:homeserver     # Build para home server
npm run build:github         # Build para GitHub Pages
npm run preview              # Preview do build
npm run lint                 # Validar código
```
